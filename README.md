# Shalimar Fashions — Coming Soon

Public landing page for **https://shalimarfashions.com** while the full store website is under construction.

This repository is independent of the Cash Counter app (hosted separately at **https://cc.shalimarfashions.com**).

## Stack

- Static HTML / CSS / JS
- Three.js silk-ribbon WebGL scene
- GitHub Pages + custom domain

## Local preview

```bash
npx --yes serve .
```

## Deploy

Push to `main`. GitHub Pages serves the repository root.

Custom domain: `shalimarfashions.com` (see `CNAME`).
